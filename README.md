# 学生管理与统计系统

这是一个可离线运行的最小错题管理系统。数据、作业照片均保存在本文件夹中。

## 启动方法

双击 `启动系统.command`，随后浏览器会自动打开 `http://localhost:8765`。

如果 macOS 阻止首次启动，请右键点击该文件，选择“打开”。

## 已实现功能

- 账号登录与注册，分老师、学生、管理员三种身份（管理员内置账号 root，可管理账号与全部班级）
- 课堂内容报告按「班级 + 日期 + 第几节」每节课导入一次，学生作业随后分多批挂到这节课下
- 班级与学生名单管理
- 课堂座位图：自定义行×列，点座位记录学生、课堂表现标签与记录，做题照片支持 Ctrl+V 截图粘贴上传
- 总结 Agent：分析学生当节课的做题截图与错题，生成家长可读的学习总结（Markdown）；Agent 的定位可在“设置”中编辑 agent.md 修改，无截图时拒绝生成以防编造
- 导入作业时选择上课日期与第几节课，同一天可分别记录不同班级的课
- 总览页按班级筛选统计，并显示今日课表
- 在“设置”中选择阿里云百炼模型并填入 API Key（仅需一次）
- 上传课堂内容报告与整批学生作业，AI 自动读取课堂重点、学生姓名和错题
- AI 自动生成知识点分类、错误类型与班级统计；低置信度结果自动标记待确认
- 待确认错题标记
- 班级知识点错误人数、高频错题和错误类型统计图
- 本地 JSON 数据与照片存储

## 当前 MVP 边界

本版本已接入阿里云百炼的 Qwen 多模态模型。可在设置中从效果优先、推荐、速度优先三种模型中选择；全部支持图像理解。请在上传前确认图片清晰，且不确定的 AI 判断仍应由老师确认。

API Key 与账号密码哈希保存在项目外的 `~/.student-stats/`（`settings.json` 和 `users.json`），不会随项目打包或上传外泄。也可以用环境变量提供 Key：`STUDENT_STATS_QWEN_KEY` / `STUDENT_STATS_KIMI_KEY` / `STUDENT_STATS_MIMO_KEY`（环境变量优先于设置页保存的 Key）。

项目已附带 `.gitignore`：`data.json`（学生数据）、`uploads/`（作业照片）、`agent输出/`、`agent.md`（个人定制）都不会被提交。打包 zip 发给别人时，同样建议排除这几项——对方拿到的是纯净代码，首次运行会自动生成默认配置。

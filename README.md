# 学生管理与统计系统

本地运行的学生错题管理与统计系统，面向中小学老师。V0.3 增加了完整的学生信息管理底座。

## 启动方法

双击 `启动系统.command`，浏览器自动打开 `http://localhost:8765`。首次双击如被 macOS 阻止，右键选"打开"。

## 首次登录

首次启动会创建管理员账号 `root`，并在终端显示一次随机初始密码。登录后请立即修改密码。

也可以在首次启动前通过环境变量指定管理员账号和密码：

```bash
export STUDENT_STATS_ADMIN_USERNAME="root"
export STUDENT_STATS_ADMIN_PASSWORD="请替换为强密码"
python3 server.py
```

## 已实现功能（V0.3）

### 课次工作流
- 以课次为核心：开课 → 考勤（默认全员已到）→ 课堂记录（座位+表现）→ 课后作业（上传/粘贴/AI 分析）→ 待确认 → 班级学情 → 学生反馈
- 同一日期+节次全局限一节课；考勤默认全员已到，老师只需改迟到/请假/缺勤/早退

### 学生信息管理（V0.3 新增）
- **学生档案**：稳定 studentId 作为内部身份，姓名仅用于展示。支持学号（全局唯一）、性别、入学年份、联系方式、备注、状态（在读/转出/休学/毕业/已归档）
- **班级名单管理**：表格展示，按姓名/学号搜索，按班级/状态筛选，支持按班级导出 CSV（utf-8 BOM，Excel 直接打开不乱码）
- **学生详情**：基本信息 + 考勤/作业/错题统计 + 最近课堂表现 + 最近课次 + 反馈文件
- **转班**：学生转班后写入变动历史；旧课次名单快照不变，新课次按当前在读学生加载
- **归档**：学生归档不删除历史错题、考勤和作业记录
- **批量导入**：粘贴文本或上传 CSV/XLSX → 预览（区分新/冲突/重复/错误）→ 老师确认 → 原子写入。学号重复自动跳过，无学号同名提示冲突
- **班级删除保护**：有在读学生或历史课次时阻止删除，引导归档

### 学生账号绑定（V0.3）
- 学生账号通过 studentId 绑定学生档案（不再靠姓名动态匹配）
- 同名学生靠绑定关系正确区分
- 管理员创建学生账号时必须绑定学生，绑定后学生登录仅看到自己数据
- 旧学生账号自动迁移：姓名唯一匹配则自动绑定，否则标为"待绑定"

### 课堂座位
- 自定义行×列，点座位记录学生、课堂表现标签与课堂记录，做题截图支持 Ctrl+V 粘贴上传

### 多模型 AI
- 阿里云百炼 Qwen / Kimi / 小米 MiMo / DeepSeek 四种厂商，每个厂商多个模型，在设置中选一个填一次 Key
- AI 分析作业图片时老师先选学生，AI 只分析内容不识别归属

### 作业导入 Agent（V0.3 新增）
- 独立会话页（左侧导航"作业导入 Agent"）：Kimi 式纯对话，发材料即可
- 支持试卷照片/PDF + 成绩单 Excel + 在线平台链接 + 作业本照片
- 多步工具调用：解析表格/PDF、联网搜索（DuckDuckGo 免费）、抓网页、查看图片、建草稿
- 课次归属在对话中确认；草稿确认前不写数据

### 总结 Agent
- 内置通用/语文/算法评判模板，老师可在 agents/ 目录创建自己的智能体
- 每个智能体可单独绑定模型；无做题截图时拒绝生成以防编造

### 数据备份与恢复（V0.3 新增）
- 完整备份：data.json + uploads + agent输出 + agents，一键下载 zip
- 从备份恢复：上传 zip → 校验格式 → 二次确认 → 恢复。恢复前自动备份当前数据到 `~/.student-stats/restore-backups/`
- API Key 和账号密码不在备份中（保存在 `~/.student-stats/`），恢复后需重新配置

## 安全说明

- API Key 与账号密码哈希保存在 `~/.student-stats/settings.json` 和 `users.json`，位于项目目录外，随项目打包或 git push 不会泄露
- 环境变量：`STUDENT_STATS_QWEN_KEY` / `_KIMI_KEY` / `_MIMO_KEY` / `_DEEPSEEK_KEY`（优先于设置页保存的 Key）
- 管理员初始密码不写入源码；可通过 `STUDENT_STATS_ADMIN_PASSWORD` 设置，未设置时由系统随机生成
- `.gitignore` 已排除：`data.json`、`uploads/`、`agent输出/`、`agent.md`、`agents/`、`.venv/`

## 数据迁移

旧 data.json 首次启动时自动迁移：
- V0.2：旧 assignments → lessons（课次模型），错题回填图片组
- V0.3：学生档案补字段（学号/性别/状态等）、课次回填名单快照、学生账号补绑定、班级补归档标记。幂等，重复运行不产生重复数据
- 迁移前自动备份到 `data_v1_backup.json`

## 技术栈

- 后端：Python 标准库（http.server）单文件，零外部依赖；智能导入助手额外需要 openpyxl + pdfplumber（首次启动自动装进 .venv）
- 前端：原生 HTML/CSS/JS，单页应用，无框架
- 数据：本地 JSON 文件 + 作业照片目录

## 接口一览

完整接口见 `AGENT_HANDOFF.md`，主要分组：
- `/api/auth/*` 登录注册
- `/api/students/*` 学生 CRUD + 批量导入 + CSV 导出
- `/api/classes/:id/archive` 班级归档
- `/api/lessons/*` 课次完整工作流
- `/api/import-agent/*` 作业导入 Agent 会话
- `/api/backup` 备份下载/恢复
- `/api/users/:id/bind` 账号绑定
- `/api/data` 业务数据（按角色过滤）
- `/api/settings` AI 模型与 Key 配置
- `/api/upload` 上传（图片/PDF/Excel/CSV，≤10MB）
